# Unique Future HR Consultancy Website

Fresh responsive static website starter for Unique Future HR Consultancy.

## Pages
Home, About, Services, Vacancies, Job Details, Apply Now, For Employers, Countries, Industries, Contact, FAQ, Privacy and Terms.

## Important
The candidate/employer/contact forms are front-end demos. Before collecting real personal information or CVs, connect them to a secure backend/form provider and review the privacy/legal text.

## GitHub Pages
Upload the complete folder contents to the repository root. GitHub Pages can then publish `index.html` as the site entry point.
